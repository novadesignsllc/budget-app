# Budget

A personal budgeting app for paying off debt. Every dollar gets a job, cards only exist as debt, and every transaction is typed in by hand.

```bash
npm install
npx expo start        # Expo Go on your phone
npx expo start --web  # desktop and web
npm test              # money logic tests
```

See `CLAUDE.md` for the product rules and code map, and `DESIGN.md` for the design system.
